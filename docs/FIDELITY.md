# C++ VNS/TS 在 Schneider E-VRPTW 上的保真度

修正仅含充电站的路线和事件标签后，92 个实例各自然完成 1 轮。原生输出的 5,247 条候选全部通过仓库公共回放器，拒绝数为 0。与论文车数相同的 31 例，平均距离差为 **+0.098%**。其余 61 例的车数和距离单列。

## 比较条件

采用作者公开的 92 例。对照取 Schneider、Stenger、Goeke（2014）表 5（第 511 页）和表 6（第 513 页）的标准 VNS/TS 栏。论文按车数、距离依次优化，报告十次运行中的最好解。本实现优化距离，每例用同一个种子运行一轮。[作者数据](https://data.mendeley.com/datasets/h3mrm5dhxw/1) · [发表版论文](https://doi.org/10.1287/trsc.2013.0490)

与修正前使用同一批输入和默认搜索参数。每例固定一个物理核，种子 20261103。批量运行最多同时处理 24 例，上一轮为 28 例，单例墙钟会受机器负载影响。一整轮包括可行性阶段及随后 200 次距离阶段 VNS 迭代。仅在原生二进制的轮次入口、出口设外部硬件断点，每例逐一检查是否自然结束及实际迭代数。轮时为单调墙钟，包含边界观测开销，排除解析输入、调试器启动及离线回放。3,600 秒保护时限均未触发。修正后二进制 SHA-256 为 `b91ff3706b14d12dac4a61379f07d0fc8c0dd94d0b3c4f608ed7c478122c01ad`。

从作者原始坐标计算双精度欧氏弧距，时间为距离除以车速、能耗为距离乘以耗能率、满充时间为补能量乘以原始充电时间系数。每条候选先独立核对起终仓、客户覆盖、容量、时间窗、电量、充电及总距离，再交由仓库公共回放器逐条复核。下表把回放距离取到论文的两位小数，减论文距离并除以论文距离得到百分比；平均值对同车数实例逐例等权计算。[公共回放](../replay.py)
